Axiom Infrastructure Setup Guide

Step 1: Install the Axiom Extension

Download the Axiom browser extension from the Chrome Web Store or official repository. This allows Tradello to communicate directly with your local node infrastructure.

Step 2: Configure RPC Endpoints

Open the Axiom settings panel. Enter your private RPC endpoint URL provided by your provider. Ensure "Fast Mode" is toggled ON for sniping latency.

Step 3: Link Phantom & Axiom

Click "Connect Phantom" in the Sniper Engine tab. When prompted, select the Axiom account you wish to use as the signer. Your SOL receiving key will automatically sync with the Axiom transaction builder.

Step 4: Verify Latency

Once connected, check the "Network Health" indicator in the bottom right corner. It should read Optimal. If it reads "High Latency", switch to a different region in the Axiom dashboard.
